# Assimil English V1

一个无需安装的英语练习网页。它实现了 Assimil 风格的六步学习流程：听、读、理解、跟读、回忆、再听。

## 如何运行

学习界面可直接双击 `index.html` 打开；AI 英文语音功能需要部署到 Vercel。详细步骤见 `DEPLOY.md`。

## 包含内容

- 3 节内置 B1 日常对话课程（可在 `lessons.json` 添加或替换）
- 六步固定学习流程
- OpenAI AI 英文语音、逐句播放、全文播放和 Shadowing 跟读
- 中文提示的柔性回忆反馈
- LocalStorage 本地保存完成记录、连续天数和复习表现
- 响应式手机/电脑界面

## 说明

学习进度只保存在本机浏览器。AI 英文语音使用 OpenAI API；密钥仅应保存于 Vercel 的环境变量中，绝不能放进前端代码。

后续可以在此基础上接入 AI 生成课程、云端账户、真人 TTS 和语音识别评分。
